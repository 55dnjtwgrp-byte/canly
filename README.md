# Canly

Rate your favorite energy drinks — like Letterboxd, but for cans.

Search a drink (Red Bull, Monster, Alani Nu, Celsius, Bang, and more), give it a
star rating out of 5, and leave a written review.

## Stack

- React + TypeScript + Vite
- Ratings are stored in the browser's `localStorage` — no backend yet.

## Getting started

```bash
npm install
npm run dev
```
